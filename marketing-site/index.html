Help

🧭 How it works

  • You describe the mobile app you want — its name and what it should do.
  • The AI Prompt Engineer asks a short set of questions tailored to your kind of app, plus a few fixed technical ones every app needs.
  • The AI generates a complete, runnable Expo project matching your answers.
  • You review it instantly in the live preview — an embedded Expo Snack, in-browser or via Expo Go.

🚀 How to use it

  1. Sign up (or log in with Google) and go to AI Generator in your dashboard.
  2. Enter your app's name and a description of what it's for.
  3. Answer the AI Prompt Engineer's tailored follow-up questions, then the fixed technical ones.
  4. Click Generate App and watch it build in the live preview, with a QR code ready for Expo Go.
  5. Export the project as a ZIP — a valid Expo project you can run locally.

📦 What it provides

  • A complete, runnable Expo/React Native app generated from a plain-language description.
  • A live, real preview (web + Expo Go), a Monaco-powered code editor, and one-click ZIP export.
  • A growing library of starter templates, with more added over time.
  • Wired-up "Build for App Store" and "Build for Play Store" actions — real store submission arrives in Phase 2.
